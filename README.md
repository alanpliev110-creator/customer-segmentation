# customer-segmentation
# Сегментация клиентской базы для разработки маркетинговой стратегии

## Описание проекта

Данный проект посвящён сегментации клиентов интернет-магазина на основе транзакционных данных.  
Основная цель — выделить группы клиентов с похожим поведением и разработать для них эффективные маркетинговые стратегии.

Сегментация позволяет:
- лучше понимать поведение клиентов;
- выявлять наиболее ценные сегменты;
- повышать эффективность маркетинга;
- увеличивать прибыль за счёт персонализации.

---

## Цель проекта

Построить модель сегментации клиентов с использованием методов анализа данных и машинного обучения и предложить практические маркетинговые рекомендации.

---

## Задачи

- Очистка и предобработка данных  
- Проведение исследовательского анализа данных (EDA)  
- Формирование признаков (RFM-анализ)  
- Кластеризация клиентов (K-Means)  
- Интерпретация полученных сегментов  
- Разработка маркетинговых рекомендаций  

---

## Данные

Набор данных: Online Retail II  

Период:
Декабрь 2009 — Декабрь 2011  

Описание:
- Онлайн-компания из Великобритании  
- Отсутствуют офлайн-магазины  
- Основной ассортимент — подарочные товары  
- Значительная часть клиентов — оптовые покупатели  

---

## Признаки

- InvoiceNo — номер транзакции (C = отмена)  
- StockCode — код товара  
- Description — описание товара  
- Quantity — количество товара  
- InvoiceDate — дата и время покупки  
- UnitPrice — цена за единицу (£)  
- CustomerID — идентификатор клиента  
- Country — страна клиента  

---

## Используемые методы

- Очистка данных  
- Формирование признаков  
- RFM-анализ:
  - Recency (давность покупки)  
  - Frequency (частота покупок)  
  - Monetary (сумма покупок)  
- Масштабирование данных (StandardScaler)  
- Кластеризация (K-Means)  

---

## Результаты

В ходе анализа клиенты были разделены на следующие сегменты:

- Лояльные клиенты  
- VIP-клиенты (высокая ценность)  
- Уходящие клиенты  
- Новые клиенты  

Ключевой вывод:
Выделенные сегменты позволяют применять персонализированные маркетинговые стратегии.
